# CA-72 0.3.1

- ULTRA uses High Fidelity numerics to reduce CPU use, with No Compromises retained as the
  lab reference. ULTRA is not bit-identical to 0.3.0; nonlinear feedback can diverge.
- HI reduces high-note and driven-output aliasing by running its open-loop VCA at 2x
  between decimator stages. FEEDBACK closes through the exact circuit preamplifier at 4x.
  HI uses more CPU than 0.3.0, especially with FEEDBACK. The 2x path retains more driven
  aliasing than the experimental 4x path, while improving substantially over 0.3.0.
- LO reduces aliasing from audio-rate filter modulation by evaluating its nonlinear
  cutoff law at 2x, and keeps the resonance limit intact across DRIVE updates.
- Contour and V-trig solves converge without the previous solver-limit spikes and caps.
  This corrects numerical behavior; the note-priority and retrigger policy stays the same.
- The circuit preamplifier eliminates linear-only nodes before solving its nonlinear
  system. Exact oscillator conversion caching and other calculation savings reduce
  repeated work without replacing the circuit equations.
- Factory HI AUTO GAIN curves are measured again. Shared HI/ULTRA curves also change the
  level of some newly selected ULTRA factory presets. Preset LEVEL values stay as set;
  saved projects retain their saved curves and settings, but the DSP changes above can
  still change their rendered sound.
- Worker-template cloning uses less stack on Windows, including when a host starts an
  instance on a thread with only 256 KB of stack.
- RETRIGGER's tooltip explains its interaction with NOTE PRIORITY. Reported latency stays
  86 samples in every quality mode.

CPU improvements depend on the patch, quality, voice count and computer. Dense ULTRA
feedback patches can still exceed the available callback time; this release does not
guarantee a particular real-time voice count.
