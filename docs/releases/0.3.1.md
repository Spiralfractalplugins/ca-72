# CA-72 0.3.1 (draft)

- HI runs the VCA at the filter's rate, reducing aliasing on high notes, and closes
  FEEDBACK's loop with the exact circuit preamplifier solve. This uses more CPU, especially
  with FEEDBACK. The factory HI AUTO GAIN curves are measured again; preset levels stay as
  set. The shared curves also change some newly loaded ULTRA presets with AUTO GAIN. LO,
  ULTRA's DSP and saved sessions, and the reported 86-sample latency are unchanged.
