# CA-72 0.3.2

- FILTER POLES selects the filter slope. FILTER MODE offers LO, BAND, STEEP HIGH and NOTCH,
  with continuous fades between modes. Existing FILTER MODE automation keeps its meaning.
- Larger lettering and clearer tips improve readability on 4K displays. Settings opens
  below its key in columns; TICKS & TITLES: QUIET reduces panel annotations.
- Modulation tips explain their routes, and the quick-start playing guide covers the controls.
- The standalone's PITCH wheel menu sets MIDI pitch-bend range. New instances remember
  the chosen window size. A published agent skill documents creating skin packs.
- POWER uses its own switch, fixing the REAPER CLAP case where it could switch off only
  once. Its lamp reflects the bypass value delivered by the host. Switching it on requests
  host un-bypass; if the host ignores that request, use the host's bypass control. Older sessions keep
  their bypass state, and presets leave POWER alone. REAPER VST3 manages its FX bypass
  separately without notifying the plug-in, so that control cannot update the lamp.
- VST3 editor changes stay applied when the host stops processing, including edits made
  while bypassed. Short-block processing and first-event CLAP automation are corrected;
  ULTRA worker setup uses less stack.
- The worker-pool rest test waits for a worker instead of relying on a brief sleep,
  avoiding a timing-dependent CI failure under load.

Filter changes can alter rendered sound when using the new modes or slopes.
